# ✦ The Vault — Cyberpunk TUI Writing Sanctuary & Audio Engine

A zero-distraction, keyboard-driven Terminal User Interface (TUI) writing environment for Linux with integrated background audio orchestration.

## Features
* **Curses Cyberpunk Dashboard (`vault`):** Organizes manuscripts into `Books`, `Poems`, and `Songs` on a pitch-black cyan/magenta matrix.
* **In-Editor Audio Daemon (`vault-music`):** Press `F5` (or `Alt + M`) inside `micro` to overlay an interactive `fzf` music selector powered by headless `mpv`.
* **Live Format-251 Opus Ripper (`get-song`):** Interactive YouTube Music search engine that extracts high-efficiency Opus/MP3 audio directly into `~/Vault/Music`.

## One-Command Install

    git clone https://github.com/Kaush-kk/the-vault-tui.git
    cd the-vault-tui && ./install.sh
